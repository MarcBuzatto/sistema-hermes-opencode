# Exemplos

Um projeto fictício (`exemplo-loja`) gerado pelo próprio cofre para você ver, no Obsidian, como ficam fatos verificados, hipóteses, um fato refutado com a correção ao lado, um fato contestado, decisões (aceita e proposta), o Estado do projeto, uma sessão e uma missão. Todas as notas têm `exemplo: true`, então as IAs e os painéis globais as ignoram. Apague esta pasta quando quiser.
