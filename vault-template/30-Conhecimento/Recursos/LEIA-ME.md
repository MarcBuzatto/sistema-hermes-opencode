# Recursos

Sites, APIs e ferramentas externas que você usa e quer que a IA abra/use quando o assunto aparecer na conversa.

Cada recurso é uma nota com `tipo: recurso`, `url` e `quando_usar`. A busca por relevância mostra o recurso para a IA sozinha quando o tema voltar — ela abre o link (ou usa a API, ou roda o comando) só quando servir. Não é fato nem evidência: é um ponteiro para algo fora do cofre.

Crie pelo modelo `Recurso` (Templates), pelo terminal (`cofre recurso "<nome>" --url ... --quando "..."`) ou peça à IA ("guarda esse site"). Recursos gerais ficam aqui; os de um projeto específico ficam em `10-Projetos/<slug>/Recursos/`.
