## No Hermes
- O plugin `cofre` coloca o contexto do projeto no seu prompt de sistema no início da sessão e lembra o foco atual a cada alguns turnos. Depois de uma compactação, chame `cofre_contexto` de novo.
- A ferramenta `memory` do Hermes serve só para preferências pessoais que o usuário confirmou explicitamente. Fatos de projeto, decisões, progresso e correções vão para o cofre, nunca para `memory`.
- Skills (também viram comandos com barra): `/cofre-checkpoint`, `/cofre-corrigir`, `/cofre-revisar`, `/cofre-notebooklm`, e `cofre-protocolo` como referência.
