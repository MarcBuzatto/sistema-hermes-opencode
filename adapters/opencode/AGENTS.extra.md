## No OpenCode
- O plugin `cofre` injeta o contexto do projeto no prompt de sistema a cada chamada; se ele não aparecer, chame `cofre_contexto`.
- Comandos do usuário: `/ctx` (carregar contexto), `/checkpoint` (salvar progresso), `/corrigir <correção>` (aplicar correção no cofre), `/revisar-cofre` (revisar hipóteses).
- Skills de apoio: `cofre-protocolo`, `cofre-checkpoint`, `cofre-corrigir`, `cofre-revisar`, `cofre-notebooklm`.
